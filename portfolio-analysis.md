# Portfolio Analysis

The **Portfolio Analysis** page helps identify which current investments are performing well, which may require attention, and how important each holding is within the overall portfolio.

The page combines return, portfolio weight, holding age, market value, price trend, and review indicators into one analytical view.

## Page overview

The page contains:

- **Current Holdings ROI** at the top
- two interactive bubble-chart views:
  - **Performance**
  - **Holding Age**
- portfolio filters
- an investment-level analysis table

Selecting an investment in a chart also highlights or filters the related information in the table.

---

## Current Holdings ROI

**Current Holdings ROI** shows the cumulative return generated by investments that are still currently held in the portfolio.

It compares the total economic gain from those holdings with the total amount invested.

The calculation considers:

- current market value
- realized sale proceeds associated with currently held investments
- investment income
- total purchase cost
- reinvested amounts
- applicable investment fees

Fully exited investments are excluded.

> **Important:** ROI is cumulative. It is not annualized and does not account for how long the investment has been held.

For example, an ROI of 40% means that the current holdings have generated economic value equal to approximately 40% of their accumulated investment cost.

# Performance view

The **Performance** chart compares the size and performance of investments currently held in the portfolio.

## Horizontal axis — Portfolio Weight

The horizontal axis shows the percentage of the portfolio represented by each investment.

An investment farther to the right represents a larger share of the current portfolio.

For example:

- 20% weight means approximately one-fifth of the portfolio is invested in that holding
- 2% weight represents a relatively small position

Portfolio weight helps identify concentration risk and determines how materially an individual investment can affect total portfolio results.

## Vertical axis — Annualized Return

The vertical axis shows the investment's annualized return.

Annualized return converts the investment's performance into an approximate yearly rate, taking the holding period into account.

Investments above the **0% line** have generated a positive annualized return.

Investments below the **0% line** have generated a negative annualized return.

The shaded area below zero visually highlights investments with negative annualized performance.

## Bubble size — Market Value

Bubble size represents the investment's **current market value**.

Larger bubbles therefore represent holdings with greater current dollar value.

This helps visually emphasize investments that have a larger financial impact on the portfolio.

> Portfolio Weight and Market Value are related, but they provide different visual cues. Portfolio Weight determines the investment's horizontal position, while Market Value determines bubble size.

## Bubble colour — Current Trend

Bubble colour represents the investment's current price trend:

- **Green — Strong Trend**
- **Orange — Mixed Trend**
- **Red — Weak Trend**

Trend is based on the investment's current market-price behaviour and is intended to provide a quick indication of recent momentum.

> **Important:** Bubble colour does **not** represent the Review classification.

An investment can therefore have a **green bubble** but still be classified as **Review** if other factors, such as a negative annualized return or meaningful portfolio exposure, indicate that the investment deserves attention.

# Holding Age view

The **Holding Age** chart provides another way to analyze the same investments.

It uses the same:

- annualized return on the vertical axis
- market value for bubble size
- current trend for bubble colour

However, the horizontal axis changes from Portfolio Weight to **Holding Age**.

## Horizontal axis — Holding Age

Holding Age represents the number of months the investment has been held.

Investments farther to the right have been held for longer periods.

This view helps answer questions such as:

- Has an underperforming investment only been held for a short period?
- Has a weak investment remained in the portfolio for several years?
- Which long-held investments have generated strong annualized returns?
- Are newer investments already showing positive or negative performance?

Holding age provides important context because the same return may have a different meaning depending on how long the investment has been owned.

# Using the tooltips

Hover over any bubble to see additional information about the investment.

The tooltip includes items such as:

- Symbol
- Portfolio Weight
- Holding Age
- Annualized Return
- Amount Invested
- Current Market Value
- ROI
- Held Since
- Length of time held
- Current Trend

The tooltip allows detailed information to be reviewed without adding excessive labels to the chart.

# Investment analysis table

The table below the chart provides detailed information for each investment.

## Review

The **Review** column provides an overall attention signal.

Possible classifications include:

- **Stable**
- **Watch**
- **Review**
- **High Priority**
- **Limited Data**

The classification considers multiple factors rather than relying only on current price trend.

These factors include characteristics such as:

- portfolio significance
- annualized return
- current trend
- availability of sufficient data

Because Review considers several factors, it may differ from the bubble colour.

## Symbol

The investment's ticker, fund code, or identifying symbol.

## Investment

The full investment or security name.

## Weight

The investment's current percentage of the portfolio.

Higher weights indicate greater portfolio concentration and a larger potential impact on overall results.

## Mkt Value

The current estimated market value of the holding.

This is also the measure used to determine bubble size in both analysis charts.

## ROI

The cumulative **Return on Investment (ROI)** for the holding.

ROI measures the total economic gain relative to total investment cost.

Unlike Annualized Return, ROI does not adjust for the amount of time the investment has been held.

## Ann. Return

The annualized return for the holding.

This makes investments held for different lengths of time easier to compare.

## Trend

The current price-trend classification:

- Strong Trend
- Mixed Trend
- Weak Trend

This is the same classification represented by bubble colour.

## vs 50D

Shows the investment's current price relative to its approximately **50-day reference level**.

This provides an indication of shorter-term price momentum.

## vs 200D

Shows the investment's current price relative to its approximately **200-day reference level**.

This provides a longer-term trend comparison.

## vs 52W-H

Shows the current price relative to the investment's **52-week high**.

A substantially negative value means the investment is trading well below its highest price over the past year.

## Insight

The Insight column briefly explains why the investment received its current Review classification.

Examples may include:

- positive return; strong trend
- 2%+ weight; mixed trend
- 2%+ weight; negative return
- negative return; weak trend

This provides a quick interpretation without requiring the user to evaluate every metric individually.

# Filters

The page contains filters that allow the analysis to be narrowed to specific investments.

Depending on the current report configuration, these may include:

## Price Source

Controls which available pricing source is used for investment valuation and market-based calculations.

## Financial Institution

Limits the analysis to investments associated with a selected financial institution.

## Purpose

Filters investments based on the financial purpose assigned to the account or holding.

## Review

Filters investments according to their Review classification.

For example, selecting **Review** can be used to focus only on investments that currently require additional attention.

# How to interpret the page

Rather than focusing on a single metric, use the page to evaluate investments from several perspectives.

### Large holding + negative return

A large position with a negative annualized return may deserve closer review because it can materially affect total portfolio performance.

### Small holding + negative return

A very small position may have poor performance but have limited impact on the total portfolio.

### Strong trend + poor historical performance

An investment may currently have a Strong Trend while still having a negative annualized return.

This can indicate that the investment is recovering even though its longer-term holding-period performance remains weak.

### Long holding period + weak return

A holding that has been owned for several years but continues to produce weak annualized results may deserve more attention than a recently purchased investment experiencing short-term volatility.

---

# Key distinction: Trend vs Review

Two different concepts are intentionally shown on this page.

**Trend** answers:

> What is the investment's recent market-price behaviour?

**Review** answers:

> Based on several factors, how much attention does this investment currently deserve?

These classifications should not be expected to always agree.

For example, an investment may show:

- **Strong Trend** — green bubble
- **Review** — red Review indicator

This is not contradictory. It means recent market momentum is positive, but another factor—such as negative annualized performance or meaningful portfolio exposure—still warrants attention.

---

# Practical use

The Portfolio Analysis page can be used to:

- identify portfolio concentrations
- locate underperforming investments
- distinguish short-term trend from longer-term performance
- understand how long investments have been held
- prioritize investments for further review
- compare cumulative ROI with annualized performance
- identify investments trading substantially below longer-term price benchmarks

The page is intended as an analytical screening tool. A Review or High Priority classification identifies an investment that may deserve further investigation; it does not by itself represent a recommendation to buy, sell, or hold an investment.
